# About

## Development

The S2GOS Generator uses [pixi](https://pixi.sh/dev/) to manage the project. You can install the development environment using

```bash
pixi install -e dev
```

### Code Style

The S2GOS client's source code is formatted and quality-controlled 
using [ruff](https://docs.astral.sh/ruff/):

```bash
ruff format
ruff check
```
